# Local AI for Photoshop

**One PowerShell script that turns a Windows PC with an NVIDIA GPU into a local, offline AI
backend for Adobe Photoshop**: ComfyUI Portable, the [OpenLayer](https://github.com/MehranMarxian/OpenLayer)
Photoshop plugin, every ComfyUI custom node OpenLayer needs and every freely-licensed model it
can use. Each step is verified, resumable and finishes with a real image generation.

[Italiano](README.it.md)

> **Unofficial community project.** Not affiliated with or endorsed by Adobe, Comfy Org,
> Black Forest Labs or the OpenLayer project. It does **not** install, activate or license
> Photoshop or Creative Cloud: you need your own licensed Photoshop 2024 or newer.

## Why

Setting this up by hand means a portable ComfyUI, the right CUDA build, around thirty model
files that each have to land in one exact folder, several custom nodes with their Python
dependencies and an unsigned `.ccx` that Adobe's installer quietly refuses in some cases.
This script does all of it, checks every file, and stops with a clear message when a step
cannot be done automatically.

## Requirements

| | Minimum | Recommended |
| --- | --- | --- |
| OS | Windows 10 1803+ / Windows 11, 64-bit | Windows 11 |
| GPU | NVIDIA, 6 GB VRAM | NVIDIA RTX, 8 GB+ VRAM |
| Driver | recent NVIDIA Studio driver | 580 or newer (CUDA 13.0) |
| RAM | 16 GB | 32 GB |
| Disk | ~25 GB (`-ModelSet Klein`) | ~140 GB free (`-ModelSet Full` or a 24 GB GPU with `Auto`) |
| Photoshop | 2024 (v25) or newer, licensed | latest |
| Creative Cloud desktop app | needed to install the plugin, signed in with any Adobe account (a free one works) | |

## Quick start

1. Download this repository (**Code > Download ZIP**) and extract it, or `git clone` it.
2. Open a **normal** (non-administrator) PowerShell in the folder and preview the plan:

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-LocalAI.ps1 -DryRun
   ```

3. Install:

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-LocalAI.ps1
   ```

4. Restart Photoshop and open **Plugins > OpenLayer**. ComfyUI must be running: start it any
   time with `Start-ComfyUI.cmd` in the install folder.

Interrupted? Run the same command again: finished files are skipped, partial downloads resume.

## What gets installed

| Step | Source | Verification |
| --- | --- | --- |
| ComfyUI Portable (NVIDIA) | latest official [Comfy-Org release](https://github.com/Comfy-Org/ComfyUI/releases) | SHA256 (GitHub digest), `7z t`, atomic extraction |
| PyTorch + CUDA check | ComfyUI's embedded Python | `torch.cuda.is_available()` |
| Models | [OpenLayer manifest](manifest/) | size + SHA256 for every file |
| Custom nodes | repositories listed by OpenLayer | class types loaded by the running ComfyUI |
| OpenLayer plugin | latest [OpenLayer release](https://github.com/MehranMarxian/OpenLayer/releases) | Adobe UPI `/list all` |
| End-to-end test | FLUX.2 [klein] 4B, 512×512, 4 steps via the ComfyUI API | valid PNG written |

### GPU advisor

Before downloading anything the script reads your GPU's VRAM and rates every OpenLayer preset,
grouped by tool, with the same rule OpenLayer's own Setup tab uses (the largest model file of a
preset against your VRAM):

```
  Text to Image
    [OK   ] FLUX.2 Klein                             7.49 GB  RECOMMENDED
    [TIGHT] Z_image_Turbo                           11.46 GB
    [SLOW ] Flux1-dev fp8                           16.06 GB  restricted licence
```

`OK` runs at full speed, `TIGHT` fits but slows down on big canvases, `SLOW` means ComfyUI keeps
part of the model in system RAM (slower, not broken). The best freely-licensed preset of each tool
is marked `RECOMMENDED`. The advisor is also saved in the report and shown by `-DryRun`.

### Model sets

| `-ModelSet` | Models | Download | Use it when |
| --- | --- | --- | --- |
| `Auto` (default) | every freely-licensed preset rated `OK` or `TIGHT` for **your** GPU | ~24 GB on 8 GB VRAM, ~64 GB on 16 GB, ~116 GB on 24 GB | you want everything that runs well on your card |
| `Full` | every model **without** a restricted licence (31 today) | ~126 GB | you want everything, even presets that will offload |
| `Klein` | the FLUX.2 [klein] 4B stack only | ~12.5 GB | small disk, or a quick start |

Models that OpenLayer marks as licence-restricted (FLUX.1 dev, FLUX.2 dev, Qwen-Image 2.1:
non-commercial or research-only) are **never downloaded by default**. To include them you must
read their licences and pass both `-IncludeLicenseRestricted -AcceptLicenses`.

OpenLayer's Sketch to Image, SD inpaint and Style Reference presets also need an **SD 1.5
checkpoint** of your choice; pass its direct URL with `-Sd15CheckpointUrl` or copy it into
`ComfyUI\models\checkpoints`.

### Where the model list comes from

`manifest/openlayer-requirements.json` is generated by OpenLayer's own build from its preset
registry (model, folder, size, SHA256, licence, custom nodes). A weekly GitHub Action rebuilds
it from the latest OpenLayer release and opens a pull request, so the installer follows the
plugin instead of a hand-maintained list. See [manifest/SOURCE.md](manifest/SOURCE.md).

## Parameters

| Parameter | Effect |
| --- | --- |
| `-Root <path>` | install folder (default `D:\AI\PhotoshopLocalAI`, or `C:\` if there is no D:) |
| `-ModelSet Auto\|Full\|Klein` | which models to install (see above) |
| `-IncludeLicenseRestricted -AcceptLicenses` | also download non-commercial / research-only models |
| `-Sd15CheckpointUrl <url>` | download an SD 1.5 checkpoint into `models\checkpoints` |
| `-DryRun` | checks + plan + download size, changes nothing |
| `-UpdateComfyUI` | update an existing ComfyUI with the official portable updater |
| `-RestartComfyUI` | restart a running ComfyUI of this install to load new nodes |
| `-InstallCreativeCloud` | install the Creative Cloud desktop app with winget (`Adobe.CreativeCloud`) |
| `-Port <n>` / `-ComfyArgs '<args>'` | ComfyUI port (default 8188) and extra launch arguments |
| `-SkipModels`, `-SkipCustomNodes`, `-SkipPlugin`, `-SkipTest`, `-NoStart` | skip a stage |
| `-SkipHardwareCheck` | continue below 6 GB of VRAM |
| `-ForceRedownload` | ignore verified files and download again |
| `-TestTimeoutSec <s>` | time limit for the end-to-end test (default 900) |
| `-ManifestPath <file>` | use another manifest file |

Optional environment variables: `HF_TOKEN` (Hugging Face), `GITHUB_TOKEN` (GitHub API rate limit).

## Result, report and exit codes

The run ends with a summary and writes `last-report.json` in the install folder (plus a copy in
`Logs\`), with system info, every model and custom node with its verification, the plugin
status, the test result and all warnings. A full transcript is in `Logs\setup-*.log`.

| Exit code | Meaning |
| --- | --- |
| `0` | everything installed and the generation test passed |
| `2` | finished with warnings or a skipped step (read the summary) |
| `1` | error: the reason is printed and stored in the report |

## Troubleshooting

| Symptom | Fix |
| --- | --- |
| `Adobe UPI -631` | Nobody is signed in to Creative Cloud. Open it, sign in (a free Adobe account works), run again. |
| `Adobe UPI -641` / plugin not installed as admin | Run from a normal, non-administrator PowerShell with Creative Cloud open. |
| "Creative Cloud is not installed" | Install it from adobe.com or with `-InstallCreativeCloud`, sign in, run again. |
| `.ccx` opens a "choose an app" dialog | Creative Cloud is missing: same as above. Do not pick another app. |
| Custom node "not loaded" | ComfyUI was already running: restart it or use `-RestartComfyUI`; otherwise read the import error in the ComfyUI console. |
| Test: "ComfyUI cannot see …" | A model is in the wrong folder or ComfyUI started before it was downloaded: restart ComfyUI. |
| Test timeout | Slow disk on the first model load: `-TestTimeoutSec 1800`. |
| OpenLayer panel not "Ready" | Panel **Settings > Find ComfyUI Active Port**; ComfyUI must be running. |
| "Agent Bridge is not connected" in the panel | Only the optional *Ask the Agent* feature uses it: just press **Generate**. |

## Uninstall

1. `"C:\Program Files\Common Files\Adobe\Adobe Desktop Common\RemoteComponents\UPI\UnifiedPluginInstallerAgent\UnifiedPluginInstallerAgent.exe" /remove OpenLayer`
2. Close ComfyUI and delete the install folder (e.g. `D:\AI\PhotoshopLocalAI`).

Nothing else is changed on the system, except 7-Zip (and Creative Cloud with
`-InstallCreativeCloud`) when they were installed through winget.

## Development

```powershell
Install-Module Pester -MinimumVersion 5.5 -Scope CurrentUser
Invoke-Pester ./tests
Invoke-ScriptAnalyzer ./Install-LocalAI.ps1 -Settings ./PSScriptAnalyzerSettings.psd1
```

Dot-sourcing the script (`. .\Install-LocalAI.ps1`) only loads its functions, which is how the
tests use it. CI runs the tests on Windows PowerShell 5.1 and PowerShell 7.
